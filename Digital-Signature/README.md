# Quản lý dự án phần mềm ký số văn bản

**Học phần:** Quản lý dự án Công nghệ thông tin  
**Năm thực hiện:** 2026  
**Hình thức:** Bài tập nhóm

### Giới thiệu
Bài tập tập trung vào lập kế hoạch, phân tích yêu cầu và quản lý quá trình xây dựng phần mềm ký số, xác minh văn bản điện tử.

### Vai trò cá nhân
- Thực hiện nội dung khảo sát và tổng hợp nhu cầu người dùng để hỗ trợ phân tích yêu cầu hệ thống.
- Phụ trách tài liệu mô tả chức năng ký văn bản hàng loạt, bao gồm luồng xử lý chính và các trường hợp ngoại lệ.
